# Owner input required

Facts, credentials and decisions only the business owner can supply. **None
of them are invented** — the platform ships with clearly-marked placeholders
and safe behaviour until each arrives: log-mode providers send nothing,
draft-only content publishes nothing, and the `[OWNER: …]` publish guard
refuses to put a placeholder in front of a visitor.

`pnpm check:readiness nuesheba` is the executable form of this document —
it fails while a blocker-marked item is missing — and the Release Gate
workflow runs exactly that command, naming the production tenant, so
nothing here can be skipped silently. Fixture tenants
(`environment.releaseEligible: false`) are reported informationally and
never gate.

## Working agreement

- Engineering proceeds on everything that does not depend on a fact above;
  missing facts leave features safely disabled, never faked.
- Placeholder values never migrate into marketing copy, JSON-LD claims or
  legal text: where a fact is missing the platform renders nothing.
- This table and `packages/business-types/src/production-readiness.ts`
  state one policy. A change to either is a change to both, in the same
  commit.
